# AIC_FTMBA

Course work for **Introduction to AI Coding in Finance** (FISF, Fudan University, Fall 2026).

## What is in here

| Folder | Contents |
|---|---|
| `src/` | Python scripts that fetch data and compute numbers |
| `data/` | Raw JSON pulled from SEC EDGAR, kept as downloaded |
| `docs/` | Task docs and notes written before the code |
| `out/` | Tables and memos generated by the scripts |

## Ground rules for this repo

- Every number must be traceable to a filing: the script prints the XBRL tag, the period end, and the filing date.
- Missing data is reported as `n/a`, never as `0`.
- Nothing is committed without reading the diff first.

## Setup

```bash
git clone git@github.com:zian96/AIC_FTMBA.git
cd AIC_FTMBA
```

Data source: [SEC EDGAR company facts API](https://data.sec.gov/api/xbrl/companyfacts/).
